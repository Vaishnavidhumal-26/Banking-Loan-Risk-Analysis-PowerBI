# Banking Loan Risk Analysis – Power BI

Interactive Banking Loan Risk Analysis Dashboard created using Power BI.

## Project Overview

This project analyzes loan applications, approval status, customer risk categories, income, loan amount, education, self-employment and CIBIL score.

## Dashboard Pages

### 1. Main Dashboard
- Total Applications
- Approved Loans
- Rejected Loans
- Approval Rate
- Average CIBIL Score
- Customer Risk Distribution
- Loan Approval by Risk Category
- Income vs Loan Amount
- Loan Approval by Education Level
- Self-Employed vs Non-Self Employed

### 2. Application Details
Provides detailed loan application information based on loan status and risk category.

### 3. Tooltip Page
Provides additional details when users interact with dashboard visuals.

## Key Insights

- 4,269 total loan applications were analyzed.
- 2,656 loans were approved.
- 1,613 loans were rejected.
- Overall approval rate was 62.22%.
- Average CIBIL score was 599.94.
- High-risk customers represented the largest risk category.
